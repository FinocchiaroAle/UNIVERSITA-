# Algebra Lineare e Geometria

Dispensa completa di studio, dimostrazioni ed esercizi svolti per il corso di **Algebra Lineare e Geometria** (Informatica, canale F–N, A.A. 2026 — Prof. Giuseppe Zappalà, UniCT), ricavata integralmente dai 15 PDF delle lezioni (`Lez00`–`Lez14`).

## File della cartella

- **`dispensa_algebra_lineare.pdf`** — Dispensa fisica A4 pronta per lo studio e la stampa, con copertina, indice cliccabile e formule renderizzate.
- **`sito/index.html`** — Sito web statico offline-first (tema Material You scuro, ricerca istantanea con `/` o `Ctrl+K`, indice laterale, formule KaTeX in locale) con la stessa interfaccia di *Programmazione I*.
- **`dispensa/*.md`** — Sorgenti Markdown per capitolo (unica fonte di verità).
- **`build.py`** — Script di compilazione che genera sia il PDF A4 sia `sito/data/book-data.js` e verifica l'assenza di errori KaTeX/JS.
